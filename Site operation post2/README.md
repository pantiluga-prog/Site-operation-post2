# Блог Алины Цыгановой — генератор постов (перманентный макияж)
Учебный проект: посты пишет языковая модель через ProxyAPI от лица мастера.

## Как это работает
1. Пользователь вводит ссылку на работу, тему поста ИЛИ загружает фото (можно фото + текст).
2. Если дана ссылка — сайт скачивает страницу и забирает текст.
3. Фото приводится к JPEG через Pillow и отправляется модели вместе с текстом.
4. Модель пишет оригинальный пост в стиле из `voice.md`.
5. Готовый пост можно: скопировать, **отредактировать карандашом ✏️**,
   **опубликовать в Telegram** (с фото, если оно приложено — картинка + текст подписью),
   сохранить **в избранное** или **отложить** на точное время
   (избранное и очередь хранятся в JSON-файлах, без базы данных).

## Запуск локально

1. Положите API-ключ в файл `.env` (уже создан):
```
PROXY_API_KEY=sk-ВАШ_КЛЮЧ
```
Ключ создаётся в кабинете ProxyAPI → «Ключи API». Баланс пополняется
в разделе «Биллинг» — без денег запросы не выполнятся.

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите сайт (порт 5001 — порт 5000 занят проектом про товары):
```bash
python app.py
```

4. Откройте в браузере:
```
http://127.0.0.1:5001
```

## Структура
- `app.py` — логика: нейросеть, Telegram, избранное, отложенные посты (с комментариями)
- `templates/index.html` — главная: ввод, готовый пост, кнопки публикации
- `templates/favorites.html` — страница «Избранное ⭐»
- `templates/scheduled.html` — страница «Отложенные ⏰»
- `static/style.css` — оформление
- `voice.md` — настройки стиля блога (краткая версия — системный промпт в `app.py`)
- `.env` — ключи (никому не показывайте, в git не коммитить)
- `.env.example` — шаблон файла `.env`
- `favorites.json`, `scheduled.json` — хранилище без базы данных (создаются сами)

## Подключаем Telegram (по шагам, простыми словами)

Чтобы кнопка «Опубликовать пост» отправляла посты в Telegram,
сайту нужны две строчки в файле `.env`: токен бота и id чата.

### Шаг 1. Создаём бота и забираем токен
1. Откройте Telegram и найдите бота **@BotFather** (с галочкой).
2. Нажмите Start и отправьте команду `/newbot`.
3. Придумайте имя бота (видно людям), например `Посты Алины`.
4. Придумайте username (латиницей, заканчивается на `bot`), например `alina_pm_posts_bot`.
   Если занят — BotFather попросит другой.
5. В ответ придёт **токен** — длинная строка вида `123456789:AAHdq...`.
   Это пароль бота: никому не показывайте.
6. Скопируйте токен в файл `.env`:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_сюда
   ```

### Шаг 2. Решаем, куда публиковать, и добавляем туда бота
- **В канал** (для подписчиков): создайте канал → «Администраторы» →
  «Добавить администратора» → найдите вашего бота → дайте право
  «Публикация сообщений».
- **В группу**: создайте группу → «Добавить участников» → добавьте бота.
- **Себе в личку** (для проверки): просто откройте чат с ботом и нажмите Start.
  Важно: сам бот первым написать вам не может — сначала вы ему.

### Шаг 3. Узнаём id чата (TELEGRAM_CHAT_ID)
1. Напишите что-нибудь в канал/группу (или боту в личку).
2. Откройте в браузере ссылку (подставьте СВОЙ токен):
   ```
   https://api.telegram.org/botВАШ_ТОКЕН/getUpdates
   ```
3. Найдите в тексте `"chat":{"id":...}` — число после `id` и есть chat_id.
   - У каналов обычно начинается с `-100`, например `-1001234567890` (минус важен!).
   - У групп — тоже отрицательное, у лички — положительное.
4. Впишите его в файл `.env`:
   ```
   TELEGRAM_CHAT_ID=-1001234567890
   ```

### Шаг 4. Перезапускаем сайт
Файл `.env` читается при запуске, поэтому **остановите сайт (Ctrl+C)
и запустите заново** (`python app.py`). Без перезапуска новые значения не подхватятся.

### Шаг 5. Проверяем
Сформируйте любой пост → «Опубликовать пост ✈» → пост должен появиться
в канале/группе/личке. Если нет — сайт покажет причину простыми словами:
неверный токен, не найден чат, не хватает прав.

### Частые вопросы
- **«Чат не найден»** — бот не добавлен в канал/группу или неверный id.
  Для канала бот обязан быть администратором.
- **«Не хватает прав»** — дайте боту право публиковать сообщения.
- **Бот молчит в личке** — сначала нажмите Start в чате с ним.
- **Отложенные посты выходят только пока сайт запущен**: планировщик живёт
  внутри сайта и проверяет очередь каждые 30 секунд.

## Смена модели
В `app.py` поменяйте константу `MODEL` на любую текстовую модель
из каталога ProxyAPI, например `openai/gpt-4o-mini`.
